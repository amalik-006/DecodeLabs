### 🔍 Project 2 — Fraud Detection Pipeline

A supervised machine learning project focused on building a fraud-detection classification pipeline for an imbalanced e-commerce transaction dataset.

**Key techniques used:**
- Data preprocessing
- Feature engineering
- Class imbalance analysis
- SMOTE oversampling
- Logistic Regression
- Random Forest
- Hyperparameter tuning
- Precision, Recall, and ROC-AUC evaluation
- Confusion matrices
- ROC curve analysis

**Best Model:** Tuned Random Forest

**Performance:**
- Precision: **1.00**
- Recall: **0.96**
- ROC-AUC: **0.9998**

📁 [View Project 2](./Project%202/)

### 🧩 Project 3 — Customer Segmentation

An unsupervised learning project focused on identifying meaningful customer segments from retail transaction data.

**Key techniques used:**
- Data preprocessing
- Feature selection
- One-Hot Encoding
- Feature scaling
- Principal Component Analysis (PCA)
- K-Means clustering
- Elbow Method
- Silhouette Score
- Cluster profiling
- Business persona development

**Optimal Clusters:** K = 4

**Customer Personas:**
- Budget / Low-Value Shoppers
- Premium High-Value Shoppers
- Bulk Value Shoppers
- Selective Premium Shoppers
